DongComDocs Official

DongComDocs 프로젝트의 공식 문서 사이트입니다. CSC 사무용 문서 제출·프로세스 관리 웹 애플리케이션의 특정 사무프로세스 자동화를 위한 주요 모듈 및 UI/UX 개선 연구의 구현체로, 관리자가 업무 프로세스와 문서 양식을 설정하면 학생은 웹에서 제출하고 시스템이 자동으로 후속 처리를 이어 줍니다.

규칙 검증 → 레이아웃 분석 → 재분석·필드 추출
시작하기 발표 자료 보기

배경

CSC 졸업·증명·신청 등 사무프로세스마다 양식과 검증 방식이 달라, 제출 현황 파악·필드 추출·집계가 반복적인 수작업에 의존합니다. DongComDocs는 이러한 업무를 설정 가능한 웹 플랫폼으로 통합하고, 문서 구조 자동 인식으로 운영 부담을 줄이는 것을 목표로 합니다.

주요 기능

Student

학생

  • 프로세스 검색·정렬
  • 기간 내 파일 제출
  • 제출 이력 조회·취소
Admin

관리자

  • 프로세스 등록·편집·공개 기간 설정
  • 제출 현황 조회, 공지사항 관리
  • PDF 템플릿 → 레이아웃 스키마·필드 bbox 자동 분석
  • 제출물 재분석 후 XLSX/ZIP 다운로드

핵심 모듈

01

템플릿·레이아웃 분석

reanalysis.ts, donutTemplateAnalysis.ts 기반으로 PDF 템플릿에서 입력 필드명과 바운딩박스를 추출합니다.

02

다중 분석 엔진

  • vLLM 터널 로컬/터널 멀티모달
  • HuggingFace Router API 비전·텍스트
  • Donut Clova DocVQA/CORD
03

재분석 파이프라인

프로세스별 제출 파일을 일괄 처리해 docType을 분류하고, 레이아웃 스키마에 맞춰 필드를 추출한 뒤 결과를 집계합니다.

기술 스택

프론트엔드
Vite, React, TypeScript
백엔드
Express, Prisma, PostgreSQL
인증
JWT, bcrypt (학번·비밀번호)
AI 연동
vLLM, Hugging Face Inference, Donut (Python)
배포
Railway (API / Web / Postgres 분리)

전체 흐름

flowchart LR
  A[관리자: 프로세스·규칙 등록] --> B[템플릿 업로드·레이아웃 분석]
  B --> C[스키마 확정]
  C --> D[학생: 문서 제출]
  D --> E[파일 규칙 검증]
  E --> F[재분석 실행]
  F --> G[필드 추출·XLSX/ZIP]

주요 화면 (관리자 워크플로우)

/admin/processes/create 프로세스 생성
/admin/processes/edit 프로세스·파일 규칙 편집
/admin/processes/layout-analysis 템플릿 분석, 스키마·bbox 편집
/admin/processes/document-processing 재분석 실행·결과 다운로드
/admin/processes/manage 제출 현황
