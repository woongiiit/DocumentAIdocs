Getting Started

DongComDocs Official은 정적 문서 사이트입니다. API 레퍼런스와 발표 자료를 로컬에서 미리보거나 Railway에 배포할 수 있습니다.

로컬 미리보기

  1. 저장소 클론
    PowerShell 
    git clone https://github.com/woongiiit/DocumentAIdocs.git
cd DocumentAIdocs
  2. 로컬 서버 실행
    PowerShell 
    python -m http.server 8080

    브라우저에서 http://localhost:8080 으로 접속합니다.

문서 구조

DocumentAIdocs/ 
DocumentAIdocs/
├── index.html              # Home
├── styles.css              # 공통 스타일
├── SubPage/
│   ├── getting-started.html
│   ├── api-reference.html  # API 목록
│   ├── api-*.html          # API 상세 페이지
│   └── documents.html      # 발표 자료 다운로드
└── documents/              # PPTX, PDF 등 실제 파일

Railway 배포

이 저장소는 백엔드 없이 nginx로 정적 파일만 서빙합니다. 앱 본체(DongComDocs)와는 별도 서비스로 배포하세요.

항목 값
서비스 이름 DongComDocs_Official
Root Directory . (저장소 루트)
Builder Dockerfile
Config-as-code /railway.json
필요 변수 없음 (정적 사이트)

기존 DongComDocs Railway 서비스는 앱 본체용입니다. 공식 문서는 DongComDocs_Official 로 새 서비스를 만들고, 이 저장소(DocumentAIdocs)를 연결하세요.
